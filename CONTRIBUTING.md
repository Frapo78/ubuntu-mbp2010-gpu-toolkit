# Contributing

Please attach a redacted diagnostic report from `scripts/collect-diagnostics.sh` when reporting hardware-specific behaviour.

Include:

- exact Mac model identifier
- Ubuntu release
- kernel
- X11 or Wayland
- GPU PCI IDs
- gmux / vga_switcheroo state
- `switcherooctl list`
- whether the issue reproduces before launching Chromium or another GPU-heavy application

Do not post serial numbers, UUIDs, account names, private filesystem paths or unrelated logs.
